# Cellkeep

Локальний інструмент, який допомагає зберегти значення CSV під час перенесення в Excel. Артикули з нулями, довгі ID, коди, схожі на дати, і формулоподібні рядки експортуються як текстові клітинки XLSX.

[Відкрити застосунок](https://tausvokse.github.io/cellkeep/) · [Завантажити офлайн-версію](https://github.com/Tausvokse/cellkeep/releases/latest)

## Як користуватися

1. Відкрий застосунок або розпакуй реліз і відкрий `index.html`.
2. Вибери CSV/TSV, перетягни файл, встав текст або натисни **Try a sample export**.
3. Перевір роздільник, кодування та прапорець заголовка. Переглянь ризикові клітинки або таблицю.
4. Натисни **Download .xlsx**. За потреби завантаж JSON-звіт; він містить початкові значення.

Файли не завантажуються на сервер. Застосунок не має аналітики чи облікових записів. Офлайн-папка працює без інтернету та встановлення Node.js.

Усі клітинки у вихідному XLSX є текстом, включно із сумами та кількостями. Для обчислень потрібні стовпці слід явно перетворити на числа в Excel. Інструмент не відновлює цифри, які вже втрачено в початковому файлі. Попередження є евристиками: поведінка Excel залежить від версії, налаштувань і локалі.

Ліміти: 5 МіБ, 25 000 записів разом із заголовком, 256 стовпців, 250 000 клітинок прямокутної таблиці. Інтерфейс першої версії англійський. Докладні можливості й обмеження — у [README](../README.md).

## Для розробки

Потрібен Node.js 22+:

```sh
npm ci
npm run check
npm start
```
