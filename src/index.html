A small tool for a costly little problem

CSV has values.
It has no cell types.

When you open CSV directly, your spreadsheet guesses. A product code can become a number. A reference can become a date. Cellkeep creates a real .xlsx workbook with explicit text cells, so the guesses never have to happen.

01 Read the original
Comma, semicolon, tab or pipe. Quoted fields and multiline text stay together. Choose a different encoding for older exports.
02 Review the sensitive values
See the source cell, exact value and reason it needs care. No values are rewritten or prefixed with apostrophes.
03 Take a workbook with you
Every cell is saved as text. A header row gets a filter and a frozen pane. Works offline from the downloaded app folder.
